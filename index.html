Five fountain symbols per frame: four from the luma bands, one spanning the whole grid on the blue axis. Manifest rides band 0 every fourth frame, so a receiver that joins late syncs within a few hundred milliseconds. Every symbol carries the session id, so a receiver can tell one object from the next without ever seeing a start or end marker.

What to measure. Band pass rate is your rolling-shutter tear rate plus read errors: four independent bands per frame means a tear costs you one symbol, not the whole frame. Chroma pass tracks separately, so you can watch the enhancement layer fall away on its own while the base layer keeps converging. Drag Green ambient up in loopback: separation on the scope drops, the blue bar stops filling, the yellow one does not. That is the layering doing its job.

Trade rate for reach. Switch Enhancement layer off and the band region collapses to black and white. It costs one symbol per frame out of five — not half the rate, since the blue plane carries a single symbol at 2×2 pitch against four luma bands — and buys about 50% more luma margin, because blue at index 2 no longer has to stay on the right side of the threshold. Worth it for long throws, coloured ambient, monochrome panels, or grids that will be screenshotted through JPEG chroma subsampling. Push Sensor noise, Defocus and Green ambient up together until the base layer starts failing, then switch the enhancement layer off: the same conditions decode again, slower.

Try the session layer. Start a transfer, then hit Swap payload partway through. The receiver reports the new object rather than mixing the two, and each file keeps its own progress — swap back and a partly received one resumes where it left off instead of restarting. See SPEC.md §4 for why identity, not begin/end markers, is the right primitive for a broadcast fountain.

Try encryption. Turn Encryption on, then set Decryption key to receiver lacks it. The read stays perfect — 100% band pass, every symbol collected, payload reassembled and checksum-verified — and it still yields nothing. Perfect reception is not the security boundary; key possession is. The filename is not in the public manifest either: it rides inside the sealed envelope.
