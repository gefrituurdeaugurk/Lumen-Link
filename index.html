Five fountain symbols per frame: four from the luma bands, one spanning the whole grid on the blue axis. Manifest rides band 0 every fourth frame, so a receiver that joins late syncs within a few hundred milliseconds. Every symbol carries the session id, so a receiver can tell one object from the next without ever seeing a start or end marker.

What to measure. Band pass rate is your rolling-shutter tear rate plus read errors: four independent bands per frame means a tear costs you one symbol, not the whole frame. Chroma pass tracks separately, so you can watch the enhancement layer fall away on its own while the base layer keeps converging. Drag Green ambient up in loopback: separation on the scope drops, the blue bar stops filling, the yellow one does not. That is the layering doing its job.

Try the session layer. Start a transfer, then hit Swap payload partway through. The receiver reports the new object rather than mixing the two, and each file keeps its own progress — swap back and a partly received one resumes where it left off instead of restarting.
